# <u> DOM (Document Object Model) </u>

- Jo browser hai vo converts karta hai HTML into a tree of objects.. That tree is called DOM
- DOM = A JavaScript representation of your HTML page.
- The **document** object represents the entire webpage.
- Yaha every HTML tag becomes a node.
- Jo dot hum use karte hai uska mtlb hota hai "Use something that belongs to this object."
---
- Jo element kisi dusre element ke andar hota hai, wo uska Child hota hai.
- Jiske andar element hota hai, wo Parent hota hai.
